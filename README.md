
🏝️ EcoAmpat Smart Tourism

EcoAmpat adalah platform Smart Tourism berbasis AI yang dirancang untuk mendukung pariwisata Raja Ampat dan Papua melalui digitalisasi destinasi, booking wisata, UMKM lokal, dashboard analitik, dan rekomendasi perjalanan berbasis AI.
